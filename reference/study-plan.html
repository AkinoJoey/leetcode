なぜ引き直したか

v1 は NeetCode Roadmap の依存順をそのまま週割りにしたもので、 各トピックに何時間かけるかを明示的に決めていませんでした。結果 DP に2週（約20時間）を積んでいました。 日系メガベンチャーの出題実態では DP は習得コストが最も高く、頻度が最も低いトピックです。 ここが v1 最大の誤配分です。

ROI表の読み方——3つの注意

  1. 表は「頻度 ÷ 習得コスト」だが、あなたが最適化すべきは「あと何時間で伸びるか」（＝限界ROI）。 配列と文字列は★5ですが、Lesson 01〜09 で最も進んだ領域です。 ★5の枠は「新パターンの追加」ではなく2問目・3問目の横展開と口頭練習の素材に使います。
  2. ★1は「ゼロでよい」ではない。DP が1問出て完全未経験なら、その面接は0点です。 削るのは2-D DPであって DP そのものではありません。1-D の3問（70 Climbing Stairs / 746 Min Cost Climbing Stairs / 198 House Robber ——いずれも習得コストの低い問題）は床として残します。
  3. 表にスタックと区間が無い。単調スタックは実質「配列と文字列」の一部で、頻出です。 v1 の第2週でスキップされているので、v2 では配列ブロックの中で拾い直します。
配分の議論が動かさないもの

ミッションは「考えを声に出しながら初見の Medium を解ききる」ことです。 どのトピックに何時間かけるかを最適化しても、口頭説明が未経験であるというリスクは1ミリも減りません。 模擬面接（8月下旬に初回・9月下旬に2〜3回）は v1 のまま維持し、再配分の対象外とします。

二分探索を打ち止めにする理由

ROI は★2、習得コストは「高」——つまりこれ以上の投資は割に合わないトピックです。 ただしすでに Lesson 14〜16 で 型A（厳密一致）・型B（境界）・型C（回転配列）を通しました。コストは支払い済みなので、 ここで止めるのが正しい。型D以降（2次元、`k`番目、二分探索の入れ子）には進みません。

そして二分探索で得たものの本体は、実は二分探索ではありません—— ⓪前提の名指し ／ ②素朴解とボトルネック ／ ⑥量と行の照合という 面接プロトコルの手続きが、この3レッスンで「獲得済み」まで来ています。 これは全トピックで使い回せます。★2のトピックで★5の道具が手に入ったので、投資は回収済みです。

「配列と文字列」に何を入れるか

★5枠なのに v1 では1週しかありませんでした。v2 では2ブロック（8/03週・9/14週）に置きます。 すでに済んでいるもの／これから足すものの区別：

  • 済：ハッシュによる O(n²)→O(n)（01）／ sliding window（02〜06）／ two pointers（07〜09）
  • ①で足す：prefix sum（区間和・部分和が K）／単調スタック（Next Greater・Daily Temperatures）／ 区間のマージ・重なり判定
  • ②で足す：既習パターンの2〜3問目。パターン名を伏せて混ぜて出す（interleaving）。 面接で必要なのは「どのパターンか」を自分で当てる技能なので、単元別に解いている限り測れません。

進捗が遅れたときの切り方（v2）

v1 の切り方は「2-D DP から」でしたが、v2 では2-D DP は最初から入っていません。 そこで削る順序を引き直します。

  1. 削ってよい：各パターンの3問目以降。Hard 問題。グラフの応用（Union-Find 等）。1-D DP の3問目。
  2. 削ってよい：バックトラック法②（8/24週）。★3だが高コストなので、遅れの吸収先はここ。
  3. 絶対に削らない：模擬面接。二分木の基本。復習の時間。配列と文字列②の再投資枠。

復習を削って新規問題を増やすのは、いちばんやりがちで、いちばん損な選択です。 実際、LR-0022 の時点で Lesson 11 の内容が3セッション連続で retrieval に出てきませんでした。これは復習量が足りていない兆候です。
