Python ハッシュ構造チートシート

面接中に手が止まらないための、最小限の構文と計算量。

計算量

操作平均最悪
x in s / d[k]O(1)O(n)
s.add(x) / d[k] = vO(1)O(n)
del d[k] / s.remove(x)O(1)O(n)
list に対する x in lstO(n)O(n)

最悪 O(n) はハッシュ衝突が総当たりになった場合。面接では「平均 O(1)」と言えば十分ですが、 聞かれたら最悪 O(n) だと即答できると一段評価が上がります。

よくある事故

「集合っぽい判定」を list でやると in が O(n) になり、ループの中で使えば静かに O(n²) に戻ります。 if x in seen: と書いた瞬間に、seen が set か dict かを必ず確認すること。

四つの道具

set — 「見たか？」だけを知りたい

seen = set()
seen.add(x)
if x in seen: ...
seen.discard(x)      # 無くてもエラーにならない（remove はエラー）

# 集合演算（そのまま O(min(n,m)) 前後）
a & b   # 積：両方にある
a | b   # 和
a - b   # 差

dict — 「値に紐づく何か」を持ちたい

d = {}
d[k] = v
d.get(k, 0)              # 無ければ既定値。KeyError を避ける定番
d.setdefault(k, []).append(v)

for k, v in d.items(): ...
if k in d: ...           # d.keys() は不要

collections.Counter — 個数を数える

from collections import Counter

c = Counter("aabbbc")           # Counter({'b':3, 'a':2, 'c':1})
c['z']                          # → 0（KeyError にならない）
c.most_common(2)                # → [('b',3), ('a',2)]
Counter(s) == Counter(t)        # アナグラム判定がこの1行

c1 - c2                         # 差（負の数は捨てられる点に注意）

collections.defaultdict — キーの初期化を省く

from collections import defaultdict

groups = defaultdict(list)
groups[key].append(word)        # キーが無くても [] から始まる

adj = defaultdict(list)         # グラフの隣接リストの定番
cnt = defaultdict(int)          # cnt[k] += 1 がそのまま書ける
defaultdict の罠

if key in d ではなく d[key] で参照しただけでキーが生成されます。 存在確認は必ず in を使うこと。

キーにできるもの／できないもの

ハッシュ可能（immutable）なものだけがキーになります。ここは Medium で頻繁に踏みます。

使える使えない回避策
str, int, tuplelisttuple(lst)

tuple のネストdictキー項目を tuple 化
 
# グリッドの座標を集合で持つ定番
visited = set()
visited.add((r, c))          # tuple なので OK。[r, c] は TypeError

# アナグラムのキー：ソート結果を tuple/str にする
key = tuple(sorted(word))    # または "".join(sorted(word))

# 文字数カウントをキーにする（O(len) で作れる）
key = tuple(count)           # count は長さ26のリスト

典型テンプレート

相方を先に問う（Two Sum 型）

seen = {}
for i, x in enumerate(nums):
    if target - x in seen:
        return [seen[target - x], i]
    seen[x] = i              # 問うてから入れる（順序が重要）

累積和 + 辞書（部分配列の和が k）

from collections import defaultdict

count = defaultdict(int)
count[0] = 1                 # 「何も足していない状態」を1回として数える
total = ans = 0
for x in nums:
    total += x
    ans += count[total - k]  # 欲しい相方＝ total - k という累積和
    count[total] += 1

グループ化（Group Anagrams 型）

groups = defaultdict(list)
for word in words:
    groups[tuple(sorted(word))].append(word)
return list(groups.values())
