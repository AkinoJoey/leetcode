選抜問題セット

提供された約140問のリストから、残り9週・約90時間に収まる56問を選抜。

選抜の原則

  • ROI表＝時間の配分／問題リスト＝配分内での選択。層が違うので競合しません。 リストの「重要度：高」はそのカテゴリを勉強するならというカテゴリ内の順位として読みます。
  • 新規は56問に留める。90時間は約110問ぶんですが、 残りは復習（解き直し）と模擬面接に充てます。新規で埋め尽くすと LR-0022 の再発（習ったことが retrieval に出てこない）になります。
  • 同一パターンは3問目で打ち切る。4問目の伸びより、未着手パターンに1問触れる方が価値が高い。
  • ★（習得コスト）の低い問題を各ブロックの入口に置く。いきなり★3から入ると詰まりが「パターン理解」なのか「実装」なのか切り分けられません。

DP について、はっきり言っておくこと

提供リストには DP が約25問（2-D、ナップサック、株の売買まで）並んでいて、すべて「重要度：高」です。 それを3問に削っています。これは意図的な賭けです—— ROI表が DP を「コスト最高・ROI最低」と評価しており、残り90時間でDPを網羅すると ★5の配列と文字列と、口頭説明の練習が確実に犠牲になるからです。
この賭けが外れる条件は1つ：志望先の選考が実質DP勝負だった場合。 もし選考情報や過去問でその兆候が出たら、すぐ言ってください。その時点で配分を組み替えます。
