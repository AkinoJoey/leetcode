二重ループをハッシュで潰す

Easy と Medium を隔てる、いちばん頻度の高い一手。

あなたのミッションは初見の Medium を45分で解ききることです。 Easy が解けて Medium で止まる人の詰まり方には、はっきりした偏りがあります。 解法は思いつくが、それが O(n²) で、そこから先に進めない——これです。

そして O(n²) から O(n) への引き上げは、その大半がたった一つの型で説明できます。 今日はその型を一つだけ、確実に手に入れます。

知識：欲しい相方を、先に言葉にする

素朴な二重ループは、いつもこう書かれます。

for i in range(n):
    for j in range(i):        # ← 内側は「過去に見た要素」を探しているだけ
        if nums[i] + nums[j] == target:
            return [j, i]

内側のループがやっている仕事は「探索」です。そして探索は、辞書に置き換えられます。 置き換えの手順は機械的です。

  1. いま見ている要素 x に対して、「どんな相方がいれば嬉しいか」を一文で言う。 Two Sum なら「target - x という値」。
  2. その一文を、そのまま辞書への問い合わせにする。if target - x in seen:
  3. 見終わった要素を辞書に入れて、次へ進む。
def two_sum(nums, target):
    seen = {}                      # 値 -> その値があった添字
    for i, x in enumerate(nums):
        if target - x in seen:     # 「欲しい相方」を先に問う
            return [seen[target - x], i]
        seen[x] = i
    return []
なぜ効くのか

ハッシュ表の検索は平均 O(1) です。内側ループ（O(n)）が定数時間の1回の問い合わせに畳まれるので、 全体が O(n²) → O(n) になります。代わりに O(n) のメモリを使う——時間をメモリで買っている、 というのが面接で口に出すべき説明です。

同じ型の、三つの顔

この型は問題ごとに姿を変えますが、正体は同じ「先に問う」です。 辞書に何を入れるかだけが違います。

辞書に入れるもの問いの形代表問題
set：見た値「この値、もう見た？」Contains Duplicate
dict：値 → 添字「相方の値はどこ？」Two Sum
Counter：値 → 個数「これ何個あった？」Group Anagrams

技能：思い出す

読んで分かるのと、45分の面接で出てくるのは別物です。ここから先は本文を見ずに答えてください。 外すのは想定内で、外したほうが定着します。

1. 配列から「和が target になる2数」を O(n) で探すとき、ループの中で最初に問うべきことは？

「欲しい相方を先に言葉にする」——x と組んで target になる相手は target - x。 それを、まだ x を辞書に入れる前に問うのが要点です（同じ要素を二度使わないため）。

2. 素朴な二重ループを「辞書で潰せる」と判断してよい合図は？

内側ループの仕事が探索なら潰せます。逆に、内側が並び替え・区間の伸縮・状態の積み上げをしているなら、 それはソートや sliding window、DP など別のパターンの領域です。

3. この型のコストとして、面接で必ず口に出すべきトレードオフは？

時間をメモリで買っています。面接官は最適化そのものより、 あなたが対価を自覚しているかを見ています。「O(n) の追加メモリと引き換えです」の一言が効きます。
