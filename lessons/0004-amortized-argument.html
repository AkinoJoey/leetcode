各文字が何回触られたか、実際に数えてください。

1. 添字1の b は、追加と除去で合計何回触られたか？

2回。right=1 で追加され、right=2 の while で除去された。 入るとき1回、出るとき1回。これが上限です。

2. どの文字も、触られる回数の上限はいくつか？

2回。入るのは1回だけ（right がその添字を通るのは1度きり。right は戻らない）。 出るのも1回だけ（left がその添字を通るのは1度きり。left も戻らない）。 合わせて2回が上限です。

3. 長さ n の文字列全体で、while ループの実行回数は最大いくつか？（n を使った式）

除去は各文字1回まで＝最大 n 回。追加も最大 n 回。合わせて 2n。 定数倍は落とすので O(n)。
重要なのは、while が1回の外側ループで何回回るかを見ないことです。 ある反復では2回回り、別の反復では0回。個別に見ると上限が決まらない。 全体で合計するから n に収まる。

これが「償却論法」

用語

償却論法（amortized analysis）：1回あたりの最悪コストではなく、 全体の合計コストを回数で割って評価する考え方。
「1回の while は最悪 n 回回るから O(n²)」は個別評価。 「while は全体で合計 n 回しか回らないから O(n)」が償却評価。
用語集にも収録。

なぜ個別評価では過大になるのか。while が長く回るには、その前にたくさん追加されている必要があるからです。 一度に10回除去できるなら、それ以前に10回追加している。除去は追加の「後払い」でしかなく、 追加の総数（n 回）を超えられません。
